# Design system inicial

Interface em português brasileiro, tema escuro e layout responsivo. Tokens CSS principais em `apps/web/styles.css`: azul `#2563EB`, fundo `#0B1220`, superfície `#111C2E`, texto `#F8FAFC`, apoio `#94A3B8`, sucesso `#16A34A`, alerta `#F59E0B` e perigo `#DC2626`. Controles têm foco visível, labels e navegação compacta em telas pequenas; movimento reduzido respeita a preferência do sistema.

Ainda não há tema claro, internacionalização runtime ou biblioteca de ícones.
